# Проект api-yamdb


## Описание проекта:
API Yamdb - это бэкенд-приложение для сбора отзывов пользователей на различные произведения (книги, фильмы, музыку). 
Сами произведения делятся на категории и жанры. Пользователи могут оставлять текстовые отзывы и выставлять оценки от 1 до 10, на основе которых автоматически рассчитывается общий средний рейтинг произведения. Также к отзывам можно добавлять комментарии.

## Как запустить проект
Клонировать репозиторий и перейти в него в командной строке:
```
git clone https://github.com/Kirullk/api-yamdb.git
```
```
cd api-yamdb
```

Создать и активировать виртуальное окружение:
```
python3 -m venv env
```

```
source env/bin/activate
```

Установить зависимости из файла requirements.txt:

```
python3 -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```

Выполнить миграции:

```
python3 manage.py migrate
```

Запустить проект:

```
python3 manage.py runserver
```

Подробная документация по API в формате Redoc доступна по адресу: 
```
http://127.0.0.1:8000/redoc
```

## Примеры запросов к API:

Получить список произведений
```
GET /api/v1/titles/
```
Получить JWT-токен (авторизация):
```
POST /api/v1/auth/token/
(Тело запроса: `{"username": "string", "confirmation_code": "string"}`)
```
Добавить отзыв (нужен токен):
```
POST /api/v1/titles/{title_id}/reviews/
(Тело запроса: `{"text": "string", "score": 1-10}`)
```
